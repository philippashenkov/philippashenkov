### Engineering approach

- **Evidence before release:** exact commits, automated tests, independent review, and auditable delivery records.
- **Practical AI:** bounded agents, clear acceptance criteria, human authorization at production boundaries.

- **Reliability first:** PostgreSQL, access controls, migration safety, CI/CD, and reproducible artifacts.
